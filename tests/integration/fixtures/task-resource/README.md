# Task/resource workflow fixture

**Purpose:** Supply authoritative language inputs for real Pafio workflow tests.

**Last updated:** 2026-10-11

The five `.styio` inputs and their `.expected` files are byte copies from the
reviewed Styio candidate at `tests/features/state_resources/` (t13, t22, t23,
e06 task-capture failure) and `tests/features/task_resources/` (e06 non-task
order). Expectations come from those directories' `expected/` files. Their
source revision and dirty candidate are recorded in the Styio task-resource
HANDOFF.md; no syntax is regenerated by the Pafio gate.

`pafio.toml` gives the same source path one binary and one test target. The gate
copies this project under an ignored build directory, then replaces only its
`src/main.styio` using these fixtures. One project covers success, compiler
error, repaired success, creation-time history (parent 9/task 7), task failure
with fallback (saved/99/saved), task failure without fallback, and f64 precision
(1.110223). Expected errors must occur in current diagnostics; successful
runtime stdout must match exactly before Pafio's completion message.

The final project is restored to t13 for the coordinator's Vityo join. Raw
plans, receipts, compiler sessions and tool paths belong in ignored evidence,
not this fixture directory. The gate does not read sibling compiler sources.
